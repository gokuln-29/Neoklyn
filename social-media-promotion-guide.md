## PART 3 — HOW TO ACTUALLY POST (platform mechanics)

### LinkedIn
1. Post from your **personal profile**, not a company page — people trust
   people, not brand pages, especially for a founder-led studio.
2. Write the post in a plain text editor first (Notes app), then paste into
   LinkedIn. Keep short paragraphs (1-3 lines) with a blank line between —
   this is why the posts below have that broken-up rhythm, it's intentional
   for mobile readability.
3. Add 3-5 hashtags at the very end only: `#webdevelopment #AIdevelopment
   #startupindia #bangalore #smallbusiness` (mix based on the post topic).
4. **Best posting times (IST):** weekdays 8:30-9:30am or 12:30-1:30pm — when
   people scroll LinkedIn before/during work.
5. Reply to every comment within a few hours, especially in the first hour
   — LinkedIn's algorithm rewards early engagement with more reach.
6. When someone comments "BUILD": reply publicly with a short answer, then
   move to DM for the real qualification questions.

### Instagram
1. **Reels spec:** vertical 9:16, 1080×1920px, 15-90 seconds. Film vertically
   from the start (don't crop landscape footage — quality suffers).
2. Post native to Instagram (not shared from another app) — Instagram's
   algorithm favors uploads made directly in-app or via Reels composer.
3. Caption structure: hook line first (shows before "more"), then 2-3 short
   lines, then hashtags. Use 8-15 hashtags mixing broad (`#webdesign`) and
   niche (`#bangalorebusiness`) tags.
4. **Best posting times (IST):** 7-9pm on weekdays, when people scroll after
   work.
5. Post Stories daily even on non-Reel days — Stories keep you visible in
   the top bar and cost almost no effort (a photo + one line of text).
6. Reply to every Story reply and DM — Instagram's DM funnel only works if
   you're fast; aim to reply within a couple of hours during the day.

### YouTube Shorts
1. **Spec:** vertical 9:16, up to 60 seconds, must include `#Shorts` in the
   title or description to get pushed into the Shorts feed.
2. **This is the exact same video file you made for the Instagram Reel** —
   if the Reel runs slightly over 60 seconds, trim it for the Shorts upload
   (Instagram allows up to 90s, YouTube Shorts caps at 60s).
3. **Title:** put the hook as the title, e.g. "Agencies charge you for what
   AI already does #Shorts" — Shorts titles show as on-screen text/search,
   so make it a real hook, not a label.
4. **Description:** 1-2 lines repeating the hook + `neoklyn.com` +
   `cal.com/neoklyn`, plus `#Shorts` and 2-3 relevant tags.
5. Upload via YouTube Studio (studio.youtube.com) or the mobile app —
   Shorts can be uploaded from the same CapCut export as the Reel, no
   re-editing needed.
6. Pin a comment with the cal.com link right after publishing.

### X
1. **Format:** either a single post (280 chars) or a short thread (2-4
   posts) — condense the LinkedIn post's core point, don't just copy-paste
   the long version in.
2. Lead with the single sharpest line from the LinkedIn post as post 1 of
   the thread — X rewards a strong opening line more than LinkedIn does.
3. Post the same day as the matching LinkedIn post, a few hours after (X's
   audience skews to check feeds later in the day / evening IST).
4. 1-2 hashtags max, if any — X hashtags carry much less weight than
   Instagram's and too many reads as spam.
5. Same CTA discipline as everywhere else: one clear ask (DM QUOTE/AUDIT,
   or "reply BUILD"), plus `cal.com/neoklyn` in the final post of a thread.
6. Reply to every reply/quote-tweet — X conversations are public, so a good
   reply is itself a small piece of proof content for anyone who finds the
   thread later.

## PART 4 — HOW TO MAKE THE VIDEOS (Mac workflow)

You're on a Mac, so everything here uses free, built-in or free-tier tools —
no paid software needed.

### Screen recording (for the "AI generates code, I review it" segments)
- **Native macOS:** press `Cmd + Shift + 5` → choose "Record Entire Screen"
  or "Record Selected Portion" → click Record. Stop from the menu bar icon.
  Files save to Desktop as `.mov`.
- Record your actual editor (Claude Code / VS Code / terminal) while you
  work — this is the single highest-trust piece of content in the whole
  plan (Part 4, Rule 2 below): showing AI write code, then you catching and
  fixing something it got wrong, on camera, unscripted.

### Face-to-camera recording
- **QuickTime Player** → File → New Movie Recording → select your Mac's
  camera and mic → Record. Keep clips short (30-90 sec) — easier to edit
  and re-shoot if you flub a line.
- Natural light from a window in front of you beats any ring light. Look at
  the camera lens, not the screen.

### Editing
- **CapCut (free, Mac + mobile):** best option for Reels — has automatic
  caption generation (important: most people watch with sound off), easy
  vertical templates, trending audio library built in.
- **iMovie (free, built into every Mac):** fine for the longer YouTube videos
  — simpler timeline, less flashy, but does the job for cutting
  screen-recording + face-camera segments together.
- **Canva video editor (free tier):** good alternative if you want templated
  intros/outros with your logo.

### Basic edit workflow for a Reel / Short (same video, both platforms)
1. Import face-to-camera hook clip + screen recording B-roll into CapCut.
2. Trim to the shortest version that still makes sense (people drop off fast
   — aim for zero dead air). Keep it at or under 60 seconds so the exact
   same export works for both Instagram Reels and YouTube Shorts.
3. Auto-generate captions (CapCut: Captions → Auto Captions) — always keep
   captions on, always double-check them for errors before posting.
4. Add one on-screen text overlay for the CTA in the last 3 seconds
   ("DM 'QUOTE' for a fixed price in 24h").
5. Export at 1080×1920 once. Upload that same file to Instagram as a Reel
   and to YouTube as a Short (with the `#Shorts` tag) — no second edit.

### Repurposing (Part 7, Rule 6 below)
Every short video does triple duty: post it as an Instagram Reel, upload the
same file as a YouTube Short, and pull its single sharpest line into an X
post the same day. One recording/editing session → 3 platforms. The weekly
LinkedIn posts get the same treatment in reverse — write the LinkedIn post
first, then condense its best line into the matching X post.

   Instagram Reel + YouTube Short (identical video) + condensed X post from
   the matching LinkedIn post. No content exists that doesn't serve at
   least one platform's lead-gen goal — if a post idea doesn't end in a
   clear ask, cut it.
7. Track weekly: followers mean nothing; count DMs, audits sent, calls
   booked, quotes sent, projects won — per platform, so you can see which
   one is actually converting and shift effort toward it.
